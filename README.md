# pripara-arcade-patcher

프리파라 홍콩판 아케이드 원본에서 필요한 파일만 확인하고, **브라우저 안에서 패치 ZIP을 만드는 웹 패처**입니다. 웹 버전은 **1.0.3**, 게임 패치는 **V17**입니다.

원본 RAR·게임 파일·파일명·SHA-256·작업 보고서는 업로드하지 않습니다. 패치에 필요한 차분과 프로그램 파일은 이 저장소의 `web/`에 포함되어 있으며, 배포한 Pages 사이트의 같은 경로에서 받습니다. 별도 API·CDN·패치 서버를 사용하지 않습니다.

## 사용 방법

1. PC의 Chrome 또는 Edge에서 패처 페이지를 엽니다.
2. 본인이 준비한 `港机+4gb.rar`을 선택합니다.
3. 실행 보정과 QR 리더·경로 설정 중 필요한 항목을 선택합니다.
4. 선택한 대상 원본의 SHA-256 검사를 통과하면 패치 ZIP을 저장합니다.
5. 게임과 QRReader를 종료한 뒤 ZIP의 적용 안내에 따라 게임 폴더에 덮어씁니다.

원본 RAR는 변경하지 않으며, 웹페이지가 게임 폴더를 직접 수정하지도 않습니다. 전체 RAR을 검증하는 방식이 아니라 **선택한 대상 파일만 검사**합니다. 지원하지 않는 원본에는 패치를 적용하지 않습니다.

## 포함 범위

- 상점·추가 구매·파츠 변경·인쇄 연결과 Print의 마이·우정티켓 QR 출력
- End의 앱용 결과 QR 생략, 원래 시작 스캔과 우정티켓 입력 처리 유지
- 원본에 들어 있는 일본어 로그인 안내 패널 사용

V15 마이티켓 출력·로그인은 사용자 확인을 받았습니다. **V17 우정티켓은 격리된 원코드·이미지 검증을 통과했지만 실제 게임 내 인식은 아직 확인되지 않았습니다.** 일본판 전체를 복원한 패치는 아닙니다.

원본 게임·완성 게임 EXE·QRReader.dll은 배포하지 않습니다. 프리파라 가상카메라와 실행 헬퍼는 별도 설치가 필요하며, 현재 저장소에 설치 파일이 포함되어 있지 않습니다. 코디 리모컨도 이 프로젝트의 구성에 포함하지 않습니다.

## 로컬 실행과 배포

개발 도구에는 Node.js **22 이상**이 필요합니다. 브라우저 이용자에게 Node.js나 Python 설치를 요구하지 않습니다.

```sh
npm test
npm run check
npm run preview
```
