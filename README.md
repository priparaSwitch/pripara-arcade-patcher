# pripara-arcade-patcher

프리파라 홍콩판 아케이드 게임의 실행 파일과 설정을 수정하는 **브라우저 기반 패처**입니다. 사용자가 선택한 원본 RAR에서 필요한 파일만 읽고, 차분을 적용한 변경 파일을 ZIP으로 만듭니다.

현재 웹 프로그램은 **1.4.0**, 게임 패치는 **V28**입니다. 원본 읽기·검사·패치·ZIP 생성은 사용자 브라우저 안에서 처리합니다.

## 주요 기능

- TV 라이브에서는 신급라이브 전에 원래 상품 추첨을 준비하고 완료를 기다립니다. 첫 상점 상품과 다섯 연출 후보를 유지하며, 특수 노트에 해당 아이템 이미지를 연결합니다.
- 쥬리는 첫 상품에 따른 원래 등장 판정과 보장 조건을 사용합니다. 별도 100% 강제·고등급 재추첨·다섯 개 중 새 당첨 추첨은 하지 않습니다. 등장하지 않아도 첫 상점 상품은 유지합니다.
- TV 라이브에서는 쥬리 등장·신급라이브 분기를 유지합니다. 현재 메뉴의 드림시어터·토모티케는 해당 분기를 거치지 않습니다.
- 기본 Shop(가챠) → 기본 티켓 인쇄 → 추가구매·코인 대기 → 추가 쇼핑 → 파츠 변경 질문 → 추가 구매분 인쇄 → End로 연결합니다.
- 파츠 변경은 첫 질문에서 OK일 때만 진입합니다. Cancel이면 추가 인쇄로 진행하고, 두 번째 3DS 연동 질문은 생략합니다.
- 추가구매를 취소하면 기본 티켓을 다시 인쇄하지 않고 End로 갑니다.
- 드림시어터는 기본 큰 DreamPrint를 먼저 출력합니다. 추가 구매분은 마지막 일반 Print로 출력합니다. 토모티케의 원래 티켓 형식 선택과 복수 인쇄 미니게임 조건을 유지합니다.
- 파츠 변경은 이름·눈매 단계를 건너뛰고 헤어스타일부터 시작하며, 게임에 포함된 파츠를 선택할 수 있습니다.
- Print의 마이티켓과 우정티켓은 홍콩 앱형 QR로 출력합니다. 드림티켓 밝기 100%, End QR 표시, 일본어 로그인 안내 패널을 유지합니다.
- 게임 폴더 경로와 QRReader 설정을 수정하고 프리파라 가상카메라로 구성합니다.

## 사용 방법

1. PC의 최신 Chrome 또는 Edge에서 패처 페이지를 엽니다.
2. 지원하는 원본 `港机+4gb.rar`을 선택합니다.
3. 적용할 항목과 실제 게임 설치 폴더를 지정합니다.
4. 대상 파일 검사를 통과하면 패치 ZIP을 저장합니다.
5. 게임과 QRReader를 종료한 뒤 ZIP의 `사용방법.txt`에 따라 변경 파일을 적용합니다.

원본 RAR은 변경하지 않습니다. 결과 ZIP에는 선택한 변경 파일과 적용 안내·검사 결과 `patch-report.json`이 들어 있습니다. 웹페이지가 게임을 실행하거나 게임 폴더에 직접 덮어쓰지는 않습니다.

## 구현 구조

JavaScript 모듈과 Web Worker로 구성된 정적 프로그램입니다. 필요한 자산과 차분은 같은 사이트의 상대 경로에서 읽으며 외부 패치 서버를 사용하지 않습니다. 원본 RAR·게임 파일·파일명·검사값을 전송받는 API는 없습니다.

| 구성 | 역할 |
| --- | --- |
| `web/app.js` | 파일 선택, 패치 옵션, 진행 상태와 결과 화면 |
| `web/worker.js` | 원본 검사와 패치, 취소 및 작업 상태 관리 |
| `web/engine/rar-select.js` | RAR 헤더 확인과 선택 파일 추출 |
| `web/engine/vendor/unrar/` | WebAssembly 기반 RAR 디코더 |
| `web/engine/apply-prineo-delta.mjs` | gzip 압축된 `PPDELTA1` 차분 적용 |
| `web/engine/config-patch.mjs` | 기존 설정 형식을 유지하며 경로·카메라 값 변경 |
| `web/engine/zip.js` | 변경 파일·안내·보고서 ZIP 생성 |
| `web/data/patch-manifest.json` | 지원 원본·차분·결과·의존 파일의 검사 기준 |

차분은 원본 구간을 복사하는 COPY와 변경 바이트를 넣는 ADD 명령으로 구성됩니다. 완성 EXE 대신 사용자의 원본과 차분을 결합합니다. 로그인 안내 그림도 원본 RAR에서 읽습니다.

V28은 원래 장면 분기를 실행한 뒤 플레이 후 순서를 조정합니다. TV 상품 추첨은 신급라이브 전에 한 번 준비하며, 그 결과를 첫 상점까지 유지합니다. 노트 이미지 연결은 원래 다섯 후보의 순서를 사용합니다. 기본 인쇄와 추가 인쇄를 나누므로 추가 Shop의 원래 결과 목록을 그대로 사용합니다. CharaMake는 장면 진입 때 메뉴를 설정하고 종료 때 복원하며, 영구 파츠 소유·스탬프 비트·랭크를 전체 해금 값으로 덮지 않습니다.

기본 선택에서는 최대 6개 대상 파일의 SHA-256을 확인합니다. 실행 파일은 차분과 최종 결과의 SHA-256도 확인합니다. `QRReader.dll`은 사용자 원본의 호환성만 확인하며 결과 ZIP에는 넣지 않습니다. 이 검사는 RAR 전체의 무결성 검사가 아닙니다.

## 지원 범위

- 홍콩판의 일부 진행과 인쇄 기능을 복원하는 패치이며 일본판 전체와 같은 동작이나 일본판 P 계열 QR 로그인을 구현하지 않습니다.
- 이전 마이티켓 출력·로그인과 V19 드림 진행은 사용자 확인을 받았습니다. 현재 V28의 원 추첨·등장 판정·노트 이미지와 전체 진행은 실제 플레이 확인 전입니다. 코드 검사를 실게임 확인으로 표시하지 않습니다.
- V17 우정티켓의 실제 인식과 밝기 변경 후 새 드림 출력 확인은 남아 있습니다.
- 일부 화면 전환의 흰 효과 문제는 미해결이며, 실패한 V21 시험 보정은 제외합니다.
- 프리파라 가상카메라 드라이버·프로그램과 Windows 실행 환경은 별도로 준비해야 합니다. 카메라 선택은 프리파라 가상카메라로 고정됩니다.
- 원본 게임·완성 EXE·`QRReader.dll`·가상카메라 설치 파일·코디 리모컨은 이 프로젝트에 포함하지 않습니다.
