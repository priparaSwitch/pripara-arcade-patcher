# pripara-arcade-patcher

프리파라 홍콩판 아케이드 게임의 실행 파일과 설정을 수정하는 **브라우저 기반 패처**입니다. 사용자가 선택한 원본 RAR에서 필요한 파일만 읽고, 차분 패치를 적용한 변경 파일을 ZIP으로 만듭니다.

현재 웹 프로그램 버전은 **1.1.0**, 게임 패치 버전은 **V20.1**입니다. 원본 읽기, 검사, 패치, ZIP 생성은 사용자 브라우저 안에서 처리합니다.

## 주요 기능

- 일반 라이브의 상점 → 인쇄 → 추가구매 → 파츠 변경 → 추가 상점 → 추가 인쇄 흐름을 연결합니다.
- 드림시어터의 전용 QR 대기를 건너뛰고, 드림 설정의 상점과 DreamPrint 및 추가구매 흐름으로 연결합니다.
- Print의 마이티켓과 우정티켓을 홍콩 앱형 QR 형식으로 출력합니다.
- 드림티켓의 밝기를 100%로 설정하고, End의 홍콩 앱용 결과 QR 표시를 복구합니다.
- 원본에 포함된 일본어 로그인 안내 패널을 사용합니다.
- 게임 폴더 경로와 QRReader 설정을 수정하고 프리파라 가상카메라를 사용하도록 구성합니다.
- 실행 파일 보정과 설정 파일 수정 중 필요한 항목을 선택할 수 있습니다.

## 사용 방법

1. PC의 최신 Chrome 또는 Edge에서 패처 페이지를 엽니다.
2. 지원하는 원본 `港机+4gb.rar`을 선택합니다.
3. 적용할 항목과 실제 게임 설치 폴더를 지정합니다.
4. 대상 파일 검사를 통과하면 패치 ZIP을 저장합니다.
5. 게임과 QRReader를 종료한 뒤 ZIP의 `사용방법.txt`에 따라 변경 파일을 적용합니다.

원본 RAR은 변경하지 않습니다. 웹페이지가 게임을 실행하거나 게임 폴더에 직접 파일을 덮어쓰지는 않습니다. 결과 ZIP에는 선택한 변경 파일, 적용 안내, 검사 결과가 담긴 `patch-report.json`이 들어 있습니다.

## 구현 구조

JavaScript 모듈과 Web Worker로 구성된 정적 웹 프로그램입니다. 서버는 프로그램과 차분 파일을 제공하며, 원본 RAR·게임 파일·파일명·검사값을 전송받는 기능은 없습니다. 별도 API나 외부 패치 서버 없이 같은 사이트의 상대 경로에서 필요한 자산을 읽습니다.

| 구성 | 역할 |
| --- | --- |
| `web/app.js` | 파일 선택, 패치 옵션, 진행 상태와 결과 화면 |
| `web/worker.js` | 원본 검사와 패치 작업 실행, 취소 및 작업 상태 관리 |
| `web/engine/rar-select.js` | RAR 헤더를 확인하고 선택한 파일만 추출 |
| `web/engine/vendor/unrar/` | WebAssembly 기반 RAR 디코더 |
| `web/engine/apply-prineo-delta.mjs` | gzip 압축된 `PPDELTA1` 차분 적용 |
| `web/engine/config-patch.mjs` | 기존 설정 형식과 관련 없는 항목을 유지하면서 경로·카메라 값 변경 |
| `web/engine/zip.js` | 변경 파일과 안내·보고서를 ZIP으로 구성 |
| `web/data/patch-manifest.json` | 지원 원본, 의존 파일, 차분 및 결과 파일의 검사 기준 |

차분은 원본 구간을 복사하는 COPY와 변경 바이트를 넣는 ADD 명령으로 구성됩니다. 실행 파일 전체를 내려받는 대신 사용자의 원본과 차분을 결합합니다. 로그인 안내 그림도 원본 RAR에서 읽어 필요한 위치로 복사합니다.

기본 선택에서는 최대 6개 파일을 확인합니다. 각 대상 원본의 SHA-256을 검사하고, 실행 파일은 차분과 완성 결과의 SHA-256까지 확인합니다. `QRReader.dll`은 원본 호환성만 확인하며 결과 ZIP에는 넣지 않습니다. 이 검사는 선택한 대상 파일에 한정되며 RAR 전체의 무결성 검사는 아닙니다.

## 지원 범위

- 홍콩판 실행 파일을 기준으로 일부 장면과 인쇄 흐름을 복원하는 패치입니다. 일본판 전체와 같은 동작을 보장하지 않으며, 일반 일본판 P 계열 QR 로그인을 구현하지 않습니다.
- 마이티켓 출력·로그인과 드림시어터 전체 진행은 사용자 확인을 받았습니다. V17 우정티켓의 실제 게임 인식과 밝기 변경 후 새 드림 출력 확인은 남아 있습니다.
- 일부 화면 전환에서 흰 효과가 창 일부에만 표시되는 현상은 미해결입니다.
- 프리파라 가상카메라 드라이버·카메라 프로그램과 Windows 실행 환경은 별도로 준비해야 합니다. 카메라 선택은 프리파라 가상카메라로 고정됩니다.
- 원본 게임, 완성 게임 EXE, `QRReader.dll`, 가상카메라 설치 파일, 코디 리모컨은 이 프로젝트에 포함하지 않습니다.
