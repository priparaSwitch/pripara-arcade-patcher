# 1.3.0 / V24 준비 범위

기록일: 2026-11-06. 로컬 배포 준비본 기준입니다.

## V24 변경과 코드 근거

기본 Shop 뒤 첫 Print를 유지합니다. 그 다음 추가구매·코인 → 추가 Shop → 첫 질문에서 선택 CharaMake → 추가 구매분 Print → End로 연결합니다. TV 라이브만 쥬리·신급라이브를 유지하며, 3DS 연동 질문은 생략합니다. 기본 티켓을 추가 인쇄 목록에 다시 합치는 처리는 사용하지 않습니다.

격리된 실제 코드 검사에서 105시나리오, 원래 장면 분기 1,095회, 구매 초기화 보정 81회를 확인했습니다. 완주 72경로는 실제 End 완료에서만 종료 집계를 한 번 호출합니다. 질문 24조건·최초 질문 억제 18조건, 추가 인쇄 카운터 초기화 9조건도 확인했습니다. 화면·GPU·코인 장치·장면 자원과 일부 할당 경계는 통제된 자료를 사용한 범위입니다.

공개 대상의 V24 처리 코드 2,432바이트와 CharaMake 357바이트는 설치 후보와 같습니다. 공개 대상에서는 실패한 V21 전환 시험 후크와 본문만 제외했습니다. 기존 QR·카메라·밝기 기능과 기본 Print 코드는 유지합니다.

## 배포 준비의 최소 실행

`minimum-prepare.mjs` 비공개 준비 도구에서 실제 공개 패치 모듈을 불러오고 기본 옵션·manifest를 확인했습니다. 두 지원 원본 EXE에 각각 새 차분을 적용한 결과가 목표 EXE와 바이트 단위로 일치했습니다.

이 실행은 빈 홈·설정 폴더, 운영체제에 필요한 변수만 있는 환경, Node 파일 권한 제한을 사용했습니다. 비공개 키 환경변수 없이 패치 엔진을 불러왔고, 제공된 원본 자료와 준비본 이외의 파일 접근이 거부되는 것을 확인했습니다. 원본 DLL을 배포하거나 암호화 키를 내장한 웹 프로그램을 만들지 않습니다. 게임의 QR 기능에는 사용자가 가진 원본 `QRReader.dll`이 필요하며 패처는 SHA-256으로 호환성만 확인합니다.

V22 준비 때 통과한 40개 검사와 실제 RAR 선택 추출 검사를 이번에 전부 재실행하지는 않았습니다. RAR 추출과 로컬 패치 방식은 유지하며, 이번에는 새 차분 두 개의 실제 적용과 기본 엔진 로드만 확인했습니다.

## 공개 자료와 미확인 범위

소스·gzip 차분·소스 ZIP에는 원본 게임·완성 EXE·DLL·개인 테스트 자료를 넣지 않습니다. 공개 검사는 일반적인 개인정보·제한 키 형식과 알려진 비공개 표본에 한정되며, 모든 미지 식별자와 비밀의 부재를 보장하지는 않습니다.

추가 브라우저·실게임 확인은 진행하지 않았습니다. 실제 V24 화면·코인 입력·미니게임·BMP 출력은 사용자 확인 전입니다. 이전 마이티켓 출력·로그인과 V19 진행의 사용자 확인을 새 V24 성공으로 확대하지 않습니다.

GitHub 업로드·Pages 배포와 실제 공개 커밋·릴리즈 해시 확인은 수행하지 않았습니다. 외부 캐시와 다른 사람의 복제본은 이 로컬 준비본 범위가 아닙니다.
