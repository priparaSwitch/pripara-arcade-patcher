# 1.1.0 / V20.1 검증

검증일: 2026-11-03. 로컬 배포 준비본 기준입니다.

## 실행 결과

- `node --test --test-isolation=none tests/*.test.mjs`: 40개 통과.
- `node scripts/verify-site.mjs`: 버전, 해시, 웹 자산 목록, 동일 출처 참조, 공개 파일 형식 검사 통과.
- `node tests/real-archive.mjs <original.rar>`: 실제 원본 RAR에서 필요한 6개 파일만 검사하여 변경 파일 5개와 안내·보고서가 들어 있는 ZIP을 생성했습니다. 9,827,199,082바이트 원본 중 5,579,032바이트를 읽었습니다. 업로드는 0바이트입니다.
- 원본 EXE와 기존 카메라 보정 EXE의 두 프로필 모두 차분 적용 결과가 목표 EXE와 바이트 단위로 일치했습니다.
- `node scripts/package.mjs`: 원본 게임·개인 테스트 출력·Git 이력 없이 배포용 소스 ZIP을 생성했습니다.

위 실행은 새 소스 사본과 빈 홈·설정 폴더를 사용했습니다. 환경 변수는 운영체제·실행 도구에 필요한 목록만 허용했고, Node 파일 권한으로 소스·출력 폴더와 명시적으로 제공된 원본 자료만 읽도록 제한했습니다. 허용 범위 밖 파일 접근이 거부되는 것도 확인했습니다. 가상머신에서 게임을 실행한 검사는 아닙니다.

## 공개 파일 검사

일반적인 개인 홈 경로, 내부망 IPv4, 개인 장치 호스트, 토큰·개인키·자격증명 형식을 소스와 gzip 내부에서 검사합니다. 실제 개인 값이나 비밀키를 공개 검사 목록·테스트에 넣지 않습니다. 알려진 제한 키와 개인 프로필이 새 차분에 포함되는지도 별도 비공개 검사로 확인했습니다. 이 검사는 모든 식별자·비밀의 부재를 수학적으로 증명하지 않습니다.

## 확인 범위

드림시어터 전체 진행은 사용자 확인을 받았습니다. 밝기 100%로 변경한 뒤의 새 출력, V17 우정티켓의 실제 인식, 복구한 End QR의 새 게임 화면 확인은 남아 있습니다. 이번 웹 업데이트에서는 게임을 실행하지 않았습니다.

브라우저 자동 조작이 중단되어 이번 버전의 실제 브라우저 화면·Worker 조합 검증은 수행하지 않았습니다. Node에서 실행한 동일 패치 엔진 검증과 구분합니다. 원격 push·Pages 배포와 공개 커밋·배포 해시 확인도 이번 로컬 작업 범위에 포함하지 않습니다.
