# 변경 내역

## 1.1.0 / V20.1

- 드림시어터 선택 후 전용 QR을 기다리는 단계를 건너뜁니다.
- 드림시어터 플레이 후 신급 챌린지 없이 전용 상점 → DreamPrint → 추가구매 → 파츠 변경 → 추가 상점 → Print → End로 연결합니다. 추가구매를 취소하면 End로 이동합니다.
- 드림티켓의 두 구간에 적용되던 밝기 계수를 모두 100%로 변경합니다.
- End의 홍콩 앱용 결과 QR 표시를 복구합니다.
- 기존 일반 라이브 진행, Print의 앱형 마이티켓·우정티켓 출력, 가상카메라 고정 설정을 유지합니다.
- 웹페이지, 적용 안내, 원본·차분·결과 SHA-256 기준을 함께 업데이트합니다.

드림시어터 전체 진행은 사용자 확인을 받았습니다. 밝기 변경 후 새 출력과 V17 우정티켓의 실제 게임 인식은 아직 사용자 확인 전입니다. End QR 복구는 원래 호출과 파일 검증을 확인한 상태입니다.

실제 게임에서 문제가 남은 V21 흰색 전환 시험 보정은 포함하지 않습니다. 부분적으로 흰 사각형이 나타나는 전환은 미해결입니다.

이번 업데이트는 로컬 배포용 파일 준비입니다. 원격 저장소와 Pages에 반영되었는지는 별도로 확인해야 합니다.
