# 변경 내역

## 1.3.0 / V24

- 기본 Shop(가챠) 뒤 기본 티켓을 먼저 인쇄한 다음 추가구매·코인 대기와 추가 쇼핑으로 진행합니다.
- 추가 Shop 마지막 파츠 질문의 OK일 때만 CharaMake로 진입합니다. Cancel이면 추가 인쇄로 진행하고 3DS 질문은 생략합니다.
- 추가구매 취소 시에는 기본 티켓 재인쇄 없이 End로 갑니다. 마지막에는 추가 구매분만 인쇄합니다.
- TV 라이브에서만 쥬리·신급라이브를 유지합니다. 드림 Mission과 토모티케의 티켓 선택을 보존합니다.
- 드림 기본 큰 티켓을 먼저 인쇄하고 추가분은 일반 Print로 처리합니다. 기존 복수 인쇄 미니게임 조건을 유지합니다.
- V23 시험의 인쇄 연기와 기본 상품 합산 처리는 제거했습니다.
- V22의 파츠 선택과 기존 QR·밝기·카메라 기능은 유지하고 실패한 V21 전환 보정은 제외합니다.

격리된 기본 코드 검증은 완료했으며 V24 실제 플레이는 아직 확인 전입니다. V23은 공개 배치하지 않은 준비 단계에서 이 순서로 대체했습니다.

## 1.2.0 / V22

- 파츠 변경은 이름·눈매 단계를 건너뛰고 헤어스타일부터 시작합니다.
- 헤어스타일·헤어컬러·피부색·아이컬러·안경에 기본 디버그 전체 해금과 같은 선택 가능 처리를 적용합니다.
- 공통 CharaMake 진입을 처리하므로 일반·토모티케·드림시어터 흐름에 적용되며, 장면을 나가면 이전 메뉴 설정을 복원합니다.
- 영구 파츠 소유·스탬프 랠리 비트·랭크·엔트런스 유지 옵션은 변경하지 않습니다.
- 원본 두 종류의 차분, 결과 SHA-256, 화면과 적용 안내를 함께 갱신했습니다.
- 기존 V20.1의 인쇄·QR·진행·밝기·카메라 기능을 유지합니다. 실패한 V21 흰색 전환 보정은 계속 제외합니다.

V22의 격리된 진입·정리·소멸·설정 복원 48조건과 전체 해금 인자 전달 12조건을 검증했습니다. 실제 V22 일반 게임 플레이는 아직 확인 전입니다.

## 1.1.0 / V20.1

- 드림시어터 선택 후 전용 QR을 기다리는 단계를 건너뜁니다.
- 드림시어터 플레이 후 신급 챌린지 없이 전용 상점 → DreamPrint → 추가구매 → 파츠 변경 → 추가 상점 → Print → End로 연결합니다. 추가구매를 취소하면 End로 이동합니다.
- 드림티켓의 두 구간에 적용되던 밝기 계수를 모두 100%로 변경합니다.
- End의 홍콩 앱용 결과 QR 표시를 복구합니다.
- 기존 일반 라이브 진행, Print의 앱형 마이티켓·우정티켓 출력, 가상카메라 고정 설정을 유지합니다.
- 웹페이지, 적용 안내, 원본·차분·결과 SHA-256 기준을 함께 업데이트합니다.

드림시어터 전체 진행은 사용자 확인을 받았습니다. 밝기 변경 후 새 출력과 V17 우정티켓의 실제 게임 인식은 아직 사용자 확인 전입니다. End QR 복구는 원래 호출과 파일 검증을 확인한 상태입니다.

실제 게임에서 문제가 남은 V21 흰색 전환 시험 보정은 포함하지 않습니다. 부분적으로 흰 사각형이 나타나는 전환은 미해결입니다.

이번 업데이트는 로컬 배포용 파일 준비입니다. 원격 저장소와 Pages에 반영되었는지는 별도로 확인해야 합니다.
